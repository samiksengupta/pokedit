# Pokedit

## About Pokedit

Pokedit is a tool to fetch, edit and manage game data for a Pokemon inspired game.

### Features

- Download and store data from pokeapi
- Manage downloaded data and edit them
- Create versioning of dataset
- Export data in various formats that can be read in Godot or other game engines
